echo "# Agentic AI Debate Coach & Presentation Analysis Platform

An advanced, full-stack AI-powered debate coaching and presentation analysis platform designed to evaluate logical reasoning, detect fallacies, provide multi-agent AI insights, and track mentorship feedback.

## 🚀 Tech Stack
* **Frontend**: React, Vite, Recharts, jsPDF, Axios
* **Backend**: FastAPI, Python, Pydantic
* **Version Control**: Git & GitHub

## ✨ Key Features
1. **Debate Room**: Real-time audio/text input with streaming AI responses and logical fallacy detection.
2. **Floating AI Coach**: Multi-agent contextual assistant widget accessible across views.
3. **Admin & Coach Dashboards**: Student tracking, performance metrics, and custom feedback submission.
4. **Professional PDF Reporting**: Generate, preview, and download formal debate and analysis reports using `jsPDF`.
